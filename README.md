Automated Exam Generation System 📝
Yıldız Teknik Üniversitesi Matematik Mühendisliği bünyesinde geliştirilen, Python tabanlı akıllı sınav oluşturma otomasyonu.

🎯 Temel Amacı
Sınav hazırlama süreçlerini otomatize ederek, pedagojik dengeyi (zorluk seviyesi dağılımı) matematiksel bir modelle optimize etmek.

🧠 Teknik Mimari
Algoritma: Hedef zorluk seviyesine ulaşmak için Monte Carlo simülasyonu tabanlı seçim modeli.

Arayüz: Streamlit ile geliştirilmiş kullanıcı dostu web arayüzü.

Veri Yönetimi: SQLite ile yapılandırılmış soru bankası ve Excel (.xlsx) üzerinden toplu veri içe aktarma.

Çıktı: Tek tıkla PDF ve DOCX formatında sınav kağıdı üretimi.

🛠️ Teknoloji Yığını
Python | Streamlit | SQLite | Pandas | NumPy | ReportLab
